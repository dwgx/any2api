架構

轉換一次。
路由到任何地方。

入口格式解析成小型中間表示；上游渲染器寫出需要的協定；回應再走回來——協定相同時保持位元組不變。

  1. 01
    解析入口

    Chat、Messages、Gemini 或 Responses，包含串流與工具。

  2. 02
    選擇鏈路

    模型白名單、健康、冷卻與任務面規則決定哪個上游嘗試。

  3. 03
    轉換或直通

    跨協定走 IR；同協定保留位元組。

  4. 04
    轉發與觀測

    串流幀、終端驗證、嘗試記錄；已提交串流絕不重播。

快速開始

從 clone 到第一個請求。

建置 Go 二進位、指向一個上游，並讓服務留在 loopback。

terminal 
git clone https://github.com/dwgx/any2api.git
cd any2api/src
go build -o any2api ./cmd/any2api
cp config.example.yaml ../config.yaml
../any2api -config ../config.yaml
預設監聽：127.0.0.1:8787
config.yaml最小設定
upstreams:
  - name: primary
    protocol: openai_chat
    base_url: https://api.example.com/v1
    api_key: ${UPSTREAM_API_KEY}

models:
  - id: example-model
    upstream_model: upstream-model-name
    upstreams: ["primary"]
憑證留在環境變數或未跟蹤的本機檔案。

安全與隱私

你的金鑰只屬於你。

Any2API 不會向客戶端收集上游憑證。本倉庫沒有帳號、cookie 或生產金鑰。公開存取是刻意選擇的開關。

閱讀安全政策 →
  • ✓倉庫不含密鑰。使用 ${ENV} 引用或未跟蹤的 config.yaml。
  • ✓Loopback 優先。綁定 127.0.0.1；TLS 在審查過的反向代理終止。
  • ✓公開面預設關閉。工作階段、access key 與限制皆為 opt-in。
  • ✓管理面預設關閉。沒有 admin key 就沒有管理路由。
